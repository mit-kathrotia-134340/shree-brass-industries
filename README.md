# Shree Brass Industries

Corporate website for **Shree Brass Industries**, an ISO 9001:2015 certified manufacturer of precision brass components in Jamnagar, Gujarat.

Content and photography are taken from the company profile, product brochure and QMS certificate.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

- Home, About, Products (with category pages)
- Infrastructure, Quality, Industries, Contact

Downloads live in `public/downloads/` (profile, brochure, ISO certificate).
